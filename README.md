  To-Do List Application

A modern and responsive web application for managing daily tasks, developed using HTML, CSS, and JavaScript.

 Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Organize daily activities
- Responsive user interface

 Technologies Used

- HTML5
- CSS3
- JavaScript

 Getting Started

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
